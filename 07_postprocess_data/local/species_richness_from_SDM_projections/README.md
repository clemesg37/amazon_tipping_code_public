# Local SDM-projection species-richness data

Copy the complete cluster directory

`$AMAZON_DATA_DIR/intermediate/07_postprocess_data/species_richness_from_SDM_projections/results_mean_ETresid/`

into `data/results_mean_ETresid/` before running local plotting notebooks that use SDM-projection species richness. The copied files are the mean and SD historical, future, and delta richness GeoTIFFs organised by scenario and period. They are reproducibility inputs for local figures; the full Monte Carlo rasters in `results_ETresid/` remain cluster-side intermediate data.
