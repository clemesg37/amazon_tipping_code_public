# Regridded deforestation-scenario inputs

`regridded_deforestation_scenarios/` contains the regridded Business-as-Usual (BaU) deforestation inputs used by `prepare_deforestation_maps.ipynb`. 

The underlying scenario source is:

Soares-Filho, B. et al. *LBA-ECO LC-14 Modeled Deforestation Scenarios, Amazon Basin: 2002-2050* (Oak Ridge National Laboratory Distributed Active Archive Center, 2013). https://doi.org/10.3334/ORNLDAAC/1153
